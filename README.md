Forecast how many people watch Grand Theft Auto VI live on Twitch in each hour of its release day (2026-11-19 UTC), as five quantiles an hour, from the first hour's viewer count and the hourly curves of past big game launches. A size-conditioned kernel-weighted local median on the log scale: launch-day shapes depend on launch size, so each hour's median ratio and spread are fitted from the past launches nearest in size to this one.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` reads every `*.in` case in the input directory and writes one `*.out` forecast per case. Python 3.13, standard library only, no network, deterministic.
